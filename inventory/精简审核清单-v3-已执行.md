### ⚠️ B10 撤销原因（重要）
Aerial 的 AndroidManifest 里声明的是 **`android.intent.category.HOME.CC`**（国内定制 HOME 类别）、LEANBACK_LAUNCHER、LAUNCHER，**并不声明标准的 `android.intent.category.HOME`**。所以系统里唯一能响应 HOME 键的仍是 `com.pptv.launcher`；禁用后实测 HOME 键完全失效（从银河奇异果按主页无反应），Aerial 的桌面守护也失去了触发源。

→ 结论：**原桌面必须保持启用**，Aerial 的接管方式是「HOME 键先落到原桌面 → 无障碍守护把 Aerial 拉到前台」，每次按主页约有 4~6 秒原桌面闪现，这是该方案固有的代价，非本次操作造成。

### U 盘安装路径（事故记录）
- 现象：插 U 盘后原桌面点入口报「您访问的内容找不到了」
- 实测：U 盘挂载正常 `/dev/block/vold/8:1 → /mnt/usb/sda1`（vfat rw），盘内 APK 可读
- 原因：PPOS 没有独立文件管理器，U 盘安装入口挂在**电视管家**（`com.pptv.tvhousekeeper/.myapp.MyAppActivity` 我的应用）上，该包被禁用后入口失效
- 处理：恢复 B1 电视管家 + B2 Search；并用 `adb install` 直接把盘内 APK 装好（绕过 UI）
- 结论：**电视管家、搜索、原桌面这三个不能禁**（分别对应 U 盘安装入口、应用搜索、HOME 键）

## 6. 执行顺序

1. 禁用 B1 / B3 / B4 / B10 / B11（立即生效，可逆）
2. 卸载 D2（第三方，卸载干净）
3. 删除 D5 孤儿目录 165M
4. 删除 yfnet 缓存 254M
5. 清空 dalvik-cache → 重启（首次开机慢几分钟，属 ART 重建）

```bash
# 建议在你不看电视时执行第 5 步
adb shell pm disable-user com.pptv.tvhousekeeper
adb shell pm disable-user com.pptv.screenprotect
adb shell pm disable-user com.pptv.guide
adb shell pm disable-user com.pptv.launcher
adb shell pm disable-user com.pplive.tvplayer

adb uninstall com.gelab.devenab

adb shell rm -rf /data/app/com.hpplay.happyplay.aw-1
adb shell rm -rf "/data/media/0/Android/data/com.pptv.launcher/cache/yfnet"

adb shell rm -rf /data/dalvik-cache/*
adb reboot

# 撤销任一项禁用
adb shell pm enable <包名>
```
