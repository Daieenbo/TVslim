# 06 · 命令速查

> 前提：`adb connect 192.168.1.26:5555` 已连上，`adb root` 可用。
> Windows 下如需固定 IP，用 `adb -s 192.168.1.26:5555 shell ...`。

## 连接 / 基本信息

```bash
adb devices -l
adb connect 192.168.1.26:5555
adb root                         # userdebug 才有
adb shell id                     # uid=0(root)
adb shell getprop ro.product.model
adb shell getprop ro.build.version.release      # 5.0.1
adb shell getprop ro.build.version.sdk          # 21
adb shell getprop ro.build.type                 # userdebug
adb shell getprop ro.adb.secure
adb shell df -h
```

## 包管理

```bash
adb shell pm list packages                       # 全部
adb shell pm list packages -3                    # 第三方
adb shell pm list packages -s                    # 系统
adb shell pm list packages -d                    # 已禁用
adb shell pm list packages -e                    # 已启用
adb shell pm list packages | grep pptv

adb shell pm path com.pptv.setting               # APK 实际路径
adb shell dumpsys package com.pptv.launcher | grep -E 'codePath|versionName|flags|sharedUser|enabled'

adb shell pm disable-user com.pptv.newtvad       # 禁用（可逆，推荐）
adb shell pm enable com.pptv.newtvad             # 恢复
adb shell pm uninstall com.gelab.devenab         # 卸载第三方（慎用于系统包）
adb shell pm clear com.pptv.newtvad              # 清数据
```

## 安装 / 卸载 APK

```bash
adb install -r app.apk
adb install -r -d app.apk        # 允许降级
adb uninstall app.orchard.tv
adb shell pm install /mnt/usb/sda1/x.apk     # 从电视内部路径装（注意：adb install 要宿主机路径）
```

> 坑：`adb install /mnt/usb/...` 会报 `cannot stat` —— 那个路径在**电视上**，
> 正确做法是 `adb pull /mnt/usb/sda1/x.apk .` 再 `adb install x.apk`。

## 权限 / 设置

```bash
adb shell pm grant app.orchard.tv android.permission.WRITE_SECURE_SETTINGS
adb shell appops set app.orchard.tv SYSTEM_ALERT_WINDOW allow
adb shell cmd notification allow_listener app.orchard.tv/app.orchard.tv.guard.RevivalListener

adb shell settings get secure enabled_accessibility_services
adb shell settings get secure default_input_method
adb shell settings put global xxx yyy          # settings list 不支持，只有 get/put

adb shell wm size                              # 分辨率
adb shell wm density
```

## 系统属性（广告相关）

```bash
adb shell getprop persist.sys.advert_enable
adb shell setprop persist.sys.advert_enable 0
adb shell getprop persist.sys.advert_status
adb shell getprop persist.sys.picadvert.exit
adb shell getprop persist.advert.delay_counter
```

## 当前前台 / 桌面

```bash
adb shell dumpsys window | grep mCurrentFocus
adb shell dumpsys activity activities | grep mResumedActivity
adb shell cmd package resolve-activity --brief -a android.intent.action.MAIN -c android.intent.category.HOME
adb shell am start -n app.orchard.tv/.MainActivity
adb shell am start -a android.intent.action.MAIN -c android.intent.category.HOME
adb shell input keyevent 3                     # 模拟 HOME
```

## 文件 / 空间

```bash
adb shell ls -l /data/data/com.pptv.launcher     # 多参数 ls -la 会静默无输出，单目录查
adb shell du -sh /data/app/* 2>/dev/null         # du 存在但慢
adb pull /data/app/com.pptv.launcher-1/base.apk .
adb push local.apk /data/local/tmp/
adb shell rm -rf /data/dalvik-cache/*            # 需 root，重启后 ART 重建
adb shell df -h /data
```

## 日志 / 排障

```bash
adb shell logcat -d | grep -iE 'pptv|advert|launcher' | tail -n 50   # 无 tail 时去掉
adb logcat -c                                    # 清日志
adb shell dumpsys activity top | head -n 60
adb shell ps | grep orchard
adb reboot
adb reboot recovery                              # 谨慎
```

## 投屏排查

```bash
adb shell pm list packages | grep -iE 'cast|mirror|wfd|dlna|airplay|hpplay|playhelper'
adb shell dumpsys package com.pptv.playhelper | grep -iE 'activity|intent'
```
