# 01 · 环境与连接

## 1. 电视端要打开什么

| 开关 | 位置（PPOS 7.2） | 说明 |
|---|---|---|
| ADB 调试 | 设置 → 关于 → 连按「版本号」7 次 → 开发者选项 → USB 调试（有的机型叫「ADB 调试」） | 必须 |
| 远程协助 | 设置 → 通用/系统 → 远程协助 | 本机用的是这个入口开的调试通道 |
| 网络 | 设置 → 网络 → 已连接网络，记下 IP | 本例 `192.168.1.26` |

开完确认端口：`adb connect 192.168.1.26:5555` 能连上（默认 5555）。
有的 PPOS 版本用 `adb tcpip 5555` 也要在电视上确认弹窗。

## 2. 电脑端：platform-tools

```powershell
cd $env:USERPROFILE
curl.exe -fL -o platform-tools.zip https://dl.google.com/android/repository/platform-tools-latest-windows.zip
Expand-Archive -Force platform-tools.zip .
$env:Path = "$env:USERPROFILE\platform-tools;$env:Path"
adb version
```

macOS：`brew install android-platform-tools`；Linux：`apt install adb`。

## 3. Windows 上的三个环境变量坑（本例踩过）

Windows 版 adb 默认会把密钥和临时文件写进 `%USERPROFILE%\.android` 和 `%TMP%`。
如果电脑上有多个 ADB 工具/多个账号，容易互相覆盖私钥导致 `unauthorized` 反复出现。
本仓库的 `scripts/connect-tv.ps1` 用**独立 HOME** 隔离：

```powershell
$env:HOME              = "D:\...\tools\androidhome"
$env:USERPROFILE       = "D:\...\tools\androidhome"
$env:ANDROID_USER_HOME = "D:\...\tools\androidhome\.android"
$env:ADB_VENDOR_KEYS   = "D:\...\tools\androidhome\.android\adbkey"
$env:TMP = $env:TEMP = $env:TMPDIR = "D:\...\tools\tmp"   # 路径别带空格
```

> 首次连接电视会弹「允许 USB 调试吗？」，勾选「一律允许」。
> 若一直 `unauthorized`，删掉 `.android\adbkey*` 重新授权，或确认电视弹窗已被点过。

## 4. 连接 + 拿 root

```powershell
powershell -ExecutionPolicy Bypass -File scripts\connect-tv.ps1 -Ip 192.168.1.26
adb -s 192.168.1.26:5555 root      # userdebug 版本可直接 root，输出 restarting adbd as root
adb -s 192.168.1.26:5555 shell id  # uid=0(root) 才算成功
```

本机 `ro.adb.secure=1`、`ro.build.type=userdebug`，所以 `adb root` 可用；
正式版（user）机型通常拿不到 root，届时本仓库中依赖 root 的步骤（写 /data 下别的应用目录、清 dalvik）需要改用其它途径。

## 5. 先采一份基线（强烈建议）

```bash
adb shell getprop | grep -E 'ro.product|ro.build|ro.adb'
adb shell df -h
adb shell pm list packages -3          # 第三方
adb shell pm list packages -d          # 已禁用
adb shell pm list packages -e          # 已启用
adb shell dumpsys window | grep mCurrentFocus
adb shell settings get secure enabled_accessibility_services
```

`connect-tv.ps1 -Info` 会一次性跑完上面这些并打印。

## 6. Android 5 的 shell 有多残（会反复绊你）

这台机器的 `toolbox` 里**没有** `sed / sort / head / tail / wc / tr / find / which`，
`settings list` 也不支持（只有 `get` / `put`）。脚本里只能靠：

- `grep`（存在，但引号嵌套要小心，`-E` 有时不可靠，用简单模式）
- 多条命令用 `;` 串，别指望管道工具箱
- 批量 `ls -la a b c` 会**静默无输出**，要逐个目录 `ls -l`
- 需要复杂处理就 `adb pull` 回电脑用 PowerShell/Python 算

另外 `adb pull` 在这台机器上只有 **~0.5MB/s**，拉几十个 APK 请分批、加超时。

## 7. 常用一次性环境（PowerShell）

```powershell
$ADB = "D:\dshDesktop\DSH-WorkSpace\tools\platform-tools\adb.exe"
$TV  = "192.168.1.26:5555"
& $ADB connect $TV
& $ADB -s $TV shell getprop ro.product.model
```

后续文档统一简写为 `adb`（已连上 `$TV`）。
