# 04 · 系统精简

## 1. 先看账：8G 的瓶颈不在 /system

| 分区 | 总容量 | 已用（操作前） | 可用 |
|---|---|---|---|
| /system | 992M | 799M | 193M |
| /data | 4.0G | **2.0G** | 2.0G |
| /cache | 744M | 4.5M | 739M |
| /systembackup | 496M | 394M | 102M（出厂备份，**勿动**） |

> **禁用甚至删除 /system 里的 App，一个字节都不会回收到 /data。**
> - 禁用系统 App → 换的是**内存与后台**（以及少一堆广告入口）
> - 清缓存/孤儿目录 → 换的是**空间**
>
> 两条线分开做，别指望禁 app 能腾出空间。

## 2. 方法：怎么判断一个包能不能动

不要抄别人的禁用清单，**按这四步自己核**：

```bash
# ① 它到底装在哪、是不是系统应用升级副本
adb shell dumpsys package com.pptv.xxx | grep -E 'codePath|versionName|sharedUser|flags|enabled'
#    codePath=/system/app/...            → 系统分区，只能禁用，卸载不省空间
#    codePath=/data/app/...-1            → 升级副本，卸载会退回出厂版本
#    flags=[ ... UPDATED_SYSTEM_APP ... ]→ 同上；sharedUser=android.uid.system 的要格外小心

# ② 有多大
adb shell ls -l /system/app/com.pptv.xxx/ /data/app/com.pptv.xxx-1/

# ③ 中文名叫什么、干什么的（无 aapt 也能查，见 scripts/apk_label.py）
python scripts\apk_label.py apk\com.pptv.xxx.apk

# ④ 有没有被别的组件拉起
adb shell dumpsys activity service com.pptv.xxx
adb shell pm list packages -d -e
```

> Android 5 上 `dumpsys package` 输出很长，`grep` 一段段看，别一口气全打出来。

## 6. 三个「不能禁」（血泪）

| 包 | 禁了会怎样 | 原因 |
|---|---|---|
| `com.pptv.launcher` 原桌面 | **HOME 键完全失效** | Aerial 只声明 `HOME.CC`，不声明标准 `HOME` |
| `com.pptv.tvhousekeeper` 电视管家 | **U 盘安装入口消失**，点入口报"您访问的内容找不到了" | PPOS 无独立文件管理器，U 盘安装挂在 `.myapp.MyAppActivity` |
| `com.pptv.search` 搜索 | 应用搜索不可用 | 与原桌面/管家联动 |

## 7. 执行顺序（本次实际）

```bash
adb root

# ① 禁用（立即生效，可逆）
adb shell pm disable-user com.pptv.tvhousekeeper      # 后被撤销，见下
adb shell pm disable-user com.pptv.screenprotect
adb shell pm disable-user com.pptv.guide
adb shell pm disable-user com.pptv.launcher           # 后被撤销，见 06 事故
adb shell pm disable-user com.pplive.tvplayer
# 表三 9 个
adb shell pm disable-user com.pptv.newtvad
adb shell pm disable-user com.pptv.tvbuy
adb shell pm disable-user com.pptv.push.service
adb shell pm disable-user com.pptv.snisupdate
adb shell pm disable-user com.pptv.snisservice
adb shell pm disable-user com.pptv.diagnostics
adb shell pm disable-user com.pptv.microhelper
adb shell pm disable-user com.pptv.terminalmanager
adb shell pm disable-user com.android.phasebeam

# ② 卸载第三方
adb uninstall com.gelab.devenab

# ③ 清孤儿与缓存
adb shell rm -rf /data/app/com.hpplay.happyplay.aw-1
adb shell rm -rf "/data/media/0/Android/data/com.pptv.launcher/cache/yfnet"

# ④ 清 dalvik 并重启（第一次开机会慢几分钟，ART 重建）
adb shell rm -rf /data/dalvik-cache/*
adb reboot
```

## 10. 风险提示

- `/systembackup`（496M）是出厂备份，**不要动**。
- 卸载 `/system/app` 下的包通常无效（只删更新副本），且**不可逆**；一律用 `pm disable-user`。
- 带 `sharedUser=android.uid.system`、`uid=1000` 的包（如原桌面）禁用要格外谨慎，一旦影响开机流程可能要到恢复模式。
- 改完跑一周确认无副作用，再考虑更激进的动作。
