## 事故 1：禁用原桌面 → HOME 键完全失效

**做了什么**

```bash
adb shell pm disable-user com.pptv.launcher
```

**现象**
- Aerial 桌面已经在跑，但按遥控器 HOME 键**毫无反应**；
- 从银河奇异果等 App 按主页也出不去；
- `am start -a android.intent.action.MAIN -c android.intent.category.HOME` 报 `unable to resolve Intent`。

**原因**
Aerial 的 `AndroidManifest.xml` 只有：

```
android.intent.category.HOME.CC     ← 国内定制类别，标准 HOME 请求不匹配
LEANBACK_LAUNCHER / LAUNCHER
```

系统里**唯一的** `android.intent.category.HOME` 响应者就是 `com.pptv.launcher`。禁用它 = 没有任何 App 能接 HOME。
Aerial 的工作方式是「HOME 先由原桌面接收 → Aerial 的无障碍守护再把 Aerial 拉前台」，原桌面是链条起点。

**恢复**

```bash
adb shell pm enable com.pptv.launcher
adb reboot
```

恢复后：按 HOME → 原桌面闪现 3~6 秒 → 自动切到 Aerial。**这是该方案的固有代价，属正常现象。**

**预防**
- 原桌面（`/data/app/com.pptv.launcher-1`，uid=1000，UPDATED_SYSTEM_APP）**永不禁用**。
- 任何"换桌面"操作前，先跑
  `adb shell cmd package resolve-activity --brief -a android.intent.action.MAIN -c android.intent.category.HOME`
  确认新桌面是否真的声明了标准 HOME。

## 事故 2：开机广告素材"备份"失败，图删了才发现

**做了什么**（PowerShell 里）

```powershell
adb shell cp -rp /data/data/com.pptv.launcher/ /data/local/tmp/advert_backup/$d/
```

**现象**
- 命令"成功"，但 `/data` 被迅速占满（88MB 整目录被复制）；
- 打开 `/data/local/tmp/advert_backup` 发现里面是**整个 launcher 目录**，不是 4 个广告目录；
- 广告图在清理阶段已被删除，**真正想要的备份并不存在**。

**原因**
`$d` 是 PowerShell 变量且为空，被展开成空串；同时 `cp` 目标是 `.../advert_backup//`，于是把整个源目录复制进去。
更根本的问题：**备份落在电视 `/data` 里，和素材同分区**，既占空间又不能算"异地备份"。

**恢复**

```bash
adb shell rm -rf /data/local/tmp/advert_backup
# 素材删了没关系：persist.sys.advert_enable=0 后广告不再播；真要恢复出厂素材只能恢复出厂设置
adb reboot
```

**预防**
- 备份一律 `adb pull` 到**电脑**，并在删除前 `Get-ChildItem` 确认本地文件真的在；
- PowerShell 里的 `$` 变量、`;`、`|`：含特殊字符的 adb shell 参数用**单引号** `'...'`，或写进 `.ps1` 文件传参；
- 先 `ls` 看清目录再 `rm -rf`，操作完立刻 `df -h /data` 复检。

## 事故 3：禁了电视管家 → U 盘安装入口消失

**做了什么**
按精简清单禁用了 `com.pptv.tvhousekeeper`（电视管家）和 `com.pptv.search`（搜索）。

**现象**
插 U 盘，原桌面点"U 盘/我的应用"入口 → 提示 **「您访问的内容找不到了」**。

**排查**
- U 盘本身正常：`/dev/block/vold/8:1 → /mnt/usb/sda1`，`vfat rw`，盘内 APK 可读；
- 原因：PPOS **没有独立文件管理器**，U 盘安装入口挂在电视管家的
  `com.pptv.tvhousekeeper/.myapp.MyAppActivity`（我的应用）上，包被禁 → 入口失效。

**恢复**

```bash
adb shell pm enable com.pptv.tvhousekeeper
adb shell pm enable com.pptv.search
```

**绕行**（不改系统也能装 U 盘里的 APK）

```bash
adb shell ls /mnt/usb/sda1/*.apk
adb pull /mnt/usb/sda1/xxx.apk .
adb install xxx.apk
```

**预防**：电视管家、搜索、原桌面 —— 这三个不要禁用（分别对应 U 盘安装、应用搜索、HOME 键）。

## 附录 A：其它小坑

| 现象 | 原因/处理 |
|---|---|
| 清 `dalvik-cache` 后第一次开机**极慢**（几分钟） | ART 重建属正常，等它跑完，别断电 |
| `ls -la a b c` 静默无输出 | Android 5 toolbox 限制，改成逐个目录 `ls -l` |
| `adb pull` 很慢（~0.5MB/s） | 属该机型 adb 实现，分批拉、别一次拉几十个 APK |
| `adb install /mnt/usb/...` 报 `cannot stat` | adb install 要**宿主机**路径，先 pull 再装 |
| `settings list` 报错 | Android 5 只有 `settings get/put` |
| 反复 `unauthorized` | 用独立 `HOME`/`ADB_VENDOR_KEYS`（见 01 文档），或删 `.android\adbkey*` 重新授权 |
| 当贝市场出现两个版本 | `com.juli.dangbeimarket`（系统 4.1.2，已 disable）+ `com.dangbeimarket`（6.0.7，/data，日常用） |
| 想确认 Aerial 是否真的在前台 | `dumpsys window \| grep mCurrentFocus` 应含 `app.orchard.tv` |

```bash
# 2. 卸载 Aerial
adb uninstall app.orchard.tv

# 3. 恢复开机广告开关（如果还想要广告）
adb shell setprop persist.sys.advert_enable 1

# 4. 彻底恢复
#    设置 → 恢复出厂设置（会清 /data，/system 未改动所以系统仍是原版）
```

> 本仓库所有操作**未改动 /system 分区任何文件**，因此恢复出厂即可回到出厂软件状态
> （出厂备份在 `/systembackup`，未触碰）。

## 附录 C：不可逆操作红线

1. `rm -rf /system/**`、`mount -o rw,remount /system` 后改文件
2. `pm uninstall` 系统分区包（部分机型会连原始 APK 一起删）
3. 动 `/systembackup`、`/tvconfig`
4. `/data` 全清（`rm -rf /data/*`）—— 等于恢复出厂且可能起不来
5. 刷非官方固件（本机型固件来源极少，变砖无救）

以上任何一条都不在本仓库流程内。
